# Risk Treatment Plan

## Overview

This document outlines the treatment strategies for identified risks within NovaTech Online Store.

## Risk Treatment Table

| Risk ID | Risk Description | Inherent Risk | Treatment Strategy | Planned Control | Risk Owner | Residual Risk |
|----------|------------------|---------------|-------------------|-----------------|------------|---------------|
| R1 | Weak Password Policy | High | Mitigate | Implement MFA and Password Policy | IT Security Manager | Medium |
| R2 | SQL Injection Vulnerability | High | Mitigate | Secure Coding and Input Validation | Application Manager | Low |
| R3 | Data Breach Risk | High | Mitigate | Encryption and Access Reviews | Security Manager | Medium |
| R4 | Phishing Attacks | Medium | Mitigate | Security Awareness Training | HR & Security Team | Low |
| R5 | No Backup Policy | High | Mitigate | Automated Backup Solution | Infrastructure Manager | Low |
