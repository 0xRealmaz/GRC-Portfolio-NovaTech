# 📁 GRC Portfolio – NovaTech Online Store

## 📌 Project Overview

This project is a practical simulation of a full **GRC (Governance, Risk, and Compliance)** and **IT Audit assessment** for a fictional e-commerce company called **NovaTech Online Store**.

The goal is to apply industry frameworks in a real-world scenario to:
- Identify cybersecurity risks  
- Evaluate security posture  
- Perform compliance gap analysis  
- Propose mitigation strategies  

---

## 🏢 About the Company

**NovaTech Online Store** is a fictional online retail platform that:

- Handles customer accounts and personal data  
- Processes online payments  
- Manages orders and inventory through web and mobile applications  

Due to its nature, the company is exposed to risks such as:
- Data breaches  
- Weak authentication  
- Application vulnerabilities  

---

## 🎯 Objectives

This project aims to:

- Identify and assess security risks  
- Evaluate compliance with industry standards  
- Perform ISO 27001 gap analysis  
- Assess security posture using NIST Cybersecurity Framework  
- Develop security policies and risk mitigation strategies  

---

## 🧩 Frameworks Used

- NIST Cybersecurity Framework  
- ISO/IEC 27001 Information Security Standard  
- Risk Management Best Practices  

---

## 📂 Project Structure

- **Risk Register** → Identification and assessment of risks  
- **ISO 27001 Gap Analysis** → Identification of missing controls  
- **NIST CSF Assessment** → Evaluation of cybersecurity maturity  
- **Security Policies** → Definition of security rules and controls  
- **Risk Treatment Plan** → Risk response strategies  
- **Final Report** → Summary and recommendations  

---

## 📊 Key Deliverables

### 1. Risk Register
Structured table including:
- Risk description  
- Impact & likelihood  
- Risk level  
- Mitigation controls  

---

### 2. ISO 27001 Gap Analysis
Comparison between required controls and current state to identify security gaps.

---

### 3. NIST CSF Assessment
Evaluation across:

- Identify  
- Protect  
- Detect  
- Respond  
- Recover  

---

### 4. Security Policies
Includes:
- Password Policy  
- Access Control Policy  
- Incident Response Policy  

---

### 5. Risk Treatment Plan
Defines how risks are handled:
- Mitigate  
- Accept  
- Transfer  
- Avoid
